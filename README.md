# Umtomi

© 2026 Omyeol · https://github.com/omyeol/Umtomi

기존 Android reader와 SwiftUI iOS reader 구성을 유지한 Umtomi 프로젝트입니다.

## 폴더

- `umtomi/app`: 기존 Android 앱과 책장 화면
- `umtomi/ios/Umtomi`: 기존 SwiftUI 앱과 책장 화면
- `umtomi/Build-Android.ps1`: Windows APK 빌드 스크립트
- `CODEX_HANDOFF.md`: 기존 기능과 이번 작업의 인수인계

## 책장

Android에서는 검색 화면 상단의 책장 아이콘/메뉴로 열고, iOS에서는 책장 탭(기본 순서에서는 더 보기)으로 엽니다.

- 책장 생성, 선택, 이름 변경, 확인 후 삭제
- 책장별 2~6열, 이미지 비율을 보존하는 빈틈 없는 배치
- 책장별 메모 자동 저장
- 여러 이미지 파일 가져오기, 클립보드 이미지 붙여넣기
- 원본 파일 보관, 화면 표시용 이미지 별도 디코딩
- 전체 화면, 이미지 삭제, 가로/세로 PDF 내보내기

모바일 저장소는 앱 내부 `bookshelf`(Android), `UmtomiBookshelf`(iOS)입니다. 데스크톱 책장 데이터의 자동 가져오기나 기기 간 동기화는 포함되지 않습니다.

## APK

```powershell
cd umtomi
.\Build-Android.ps1 -Test
```

Android Studio의 JDK와 Android SDK를 사용합니다. `JAVA_HOME`/`ANDROID_HOME`을 지정할 수도 있습니다. 중간 산출물은 OneDrive 파일 잠금을 피하기 위해 로컬 임시 폴더에 생성합니다. 결과는 `artifacts/Umtomi-v5.12.0.apk`이며, 매번 `C:\Users\peopl\OneDrive\DEV\APK`에도 자동 복사하고 SHA-256을 대조합니다.

- Version: 5.12.0 (85)
- Android: 5.0 / API 21 이상
- Application ID: `xyz.sabok.umtomi` (5.8.0부터 debug 접미사 제거)
- Debug APK는 개발 서명으로 설치 가능합니다. 기존 다른 패키지 앱과 별도로 설치됩니다. 기존 Android 데이터는 원래 앱에서 백업 후 복원해야 합니다.

책장 기기 테스트:

```powershell
.\gradlew.bat connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=xyz.sabok.umtomi.BookshelfTest
```

iOS는 macOS에서 `umtomi/ios/build-ipa.sh`를 실행합니다. 이 스크립트가 `project.yml`로 Xcode 프로젝트를 다시 생성하므로 새 `Bookshelf.swift`가 포함됩니다. 이번 Windows 환경에서는 iOS 컴파일과 실행을 검증하지 않았습니다.

## Android 즐겨찾기와 테마

왼쪽 메뉴의 즐겨찾기에서 폴더와 하위 폴더를 만들고, 기존 즐겨찾기를 여러 폴더에 지정할 수 있습니다. 폴더를 길게 누르면 이름 변경과 삭제 메뉴가 나옵니다. 폴더를 삭제해도 작품의 즐겨찾기는 유지됩니다.

메뉴의 JSON 내보내기/가져오기는 모든 즐겨찾기, 폴더 구조, 즐겨찾기 태그를 파일로 보관하고 병합 복원합니다. iOS 폴더 데이터의 UUID와 필드 형식을 지원합니다. iOS의 자동 분류 규칙은 파일에서 보존하지만 Android에서는 수동 폴더 분류를 제공합니다.

다크모드 전환 시 설정을 먼저 저장하고 화면을 재생성합니다. 설정 하위 화면과 메인 검색 상태를 복원하며, 종료된 메인 화면의 작업은 취소합니다.

## Android 앱 업데이트

설정의 앱 버전을 누르면 GitHub 릴리스 확인, APK 다운로드 진행률, 설치 버튼을 볼 수 있습니다. 최신 정식 릴리스 중 설치된 빌드 종류에 맞는 APK를 선택합니다. `v5.5.0` 같은 태그와 `Umtomi-v5.5.0-debug.apk` 파일명을 사용합니다. 같은 버전이나 이전 버전은 업데이트로 안내하지 않습니다.

APK 설치 전에 패키지 이름, 버전 코드, 서명을 검사합니다. 다음 배포도 같은 서명 키를 사용하고 버전 코드를 높여야 합니다. 다운로드는 Android DownloadManager가 처리하며 화면을 다시 열어도 이어서 상태를 확인합니다. 실제 설치는 Android의 사용자 확인을 거칩니다.

앱 업데이트와 APK는 공개 저장소 https://github.com/omyeol/Umtomi-releases 에서 배포합니다. 기존 소스 저장소는 비공개로 유지합니다. GitHub 인증 정보를 APK에 포함하지 않습니다.

5.5.0 이하에서는 5.5.1 APK를 한 번 직접 설치해야 합니다. 이후 버전부터 앱 내 업데이트를 사용할 수 있습니다.

새 릴리스 게시(사용자가 배포를 요청한 경우):

```powershell
python .\Publish-AndroidRelease.py ..\artifacts\Umtomi-v5.12.0.apk --notes ..\artifacts\RELEASE-v5.10.0.md --publish
```

매번 버전명과 버전 코드를 올린 뒤 같은 서명 키로 빌드하세요. 스크립트는 기존 Git credential manager 로그인을 사용해 APK와 SHA256SUMS.txt만 게시하며, 게시된 동일 버전 파일을 덮어쓰지 않습니다.

## Android 뷰어 탭

뷰어 상단에는 열린 작품 탭이 표시됩니다. 탭을 누르면 전환하고 `×`를 누르면 닫습니다. `+`로 작품 ID를 입력해 새 탭을 열 수 있습니다. 작품 정보 화면의 읽기 버튼을 길게 누르면 현재 작품을 유지한 채 백그라운드 탭에 추가합니다. 각 탭은 마지막 읽던 페이지를 보관합니다.

사진을 한 번 누르면 제목, 탭 목록과 조작 버튼이 숨겨지거나 다시 보입니다. 사진을 길게 누르면 기존의 한 장 보기로 바뀌고, 한 장 보기에서는 길게 눌러 다음 페이지로 이동합니다.

뷰어는 어두운 배경과 민트색 강조, 둥근 작품 탭을 사용합니다. 하단의 이전/다음 버튼과 슬라이더로 페이지를 이동하고, 페이지 숫자를 누르면 번호를 직접 선택합니다. 더보기 메뉴에서 다운로드·재시도·캡처·전체 화면을 실행합니다.

## 5.8.0 뷰어·Drive

연속 보기에서 컷 사이 간격 없이 전체 컷을 함께 확대합니다. 길게 눌러 한 장 보기는 유지합니다. 메인 화면은 볼륨키로 페이지를 넘기지 않으며, 뷰어의 볼륨키 페이지 이동은 설정에서 켜고 끕니다(기본 끔).

책장과 설정에서 Google Drive 수동 동기화를 실행할 수 있습니다. 책장 원본·폴더·메모, 열람 기록, 즐겨찾기·폴더를 Umtomi 전용으로 동기화합니다. Android 8 이상에서 사용할 수 있으며 OAuth 등록이 필요합니다. [등록 및 패키지 변경 안내](GOOGLE_DRIVE_SETUP.md)를 확인하세요. 실제 Google 계정 연동은 등록 후 검증해야 합니다.

5.8.0은 이전 `.debug` 패키지와 별도로 설치되므로 APK를 직접 설치해야 합니다. 기존 데이터는 자동 이전되지 않으며 기존 앱을 삭제하지 않습니다. 이후 새 패키지에서는 앱 내 업데이트를 사용할 수 있습니다.

## 뷰어 영역 캡처 (5.9.0)

하단 캡처 아이콘을 누르면 현재 보이는 이미지 영역을 선택합니다. 모서리를 끌어 영역을 조절하고 확정한 뒤 이미지 파일 저장 또는 책장 추가를 고릅니다. 파일 저장은 Android 파일 선택기를 사용하므로 원하는 다운로드 폴더에 PNG로 저장할 수 있습니다. 책장 추가 시 저장할 책장을 선택합니다. 제목·탭·하단 조작부는 캡처에서 제외합니다. 워터마크 제거와 긴 스크롤 캡처는 포함하지 않습니다.

## 5.10.0

한 컷 보기에서 뒤로가기를 누르면 연속 보기로 돌아옵니다. 설정의 ‘길게 눌러 한 컷 보기’로 해당 제스처를 켜고 끌 수 있습니다. 연속 보기에서 캡처 후 ‘아래로 확장 · 스크롤 캡처’를 누르면 이미지가 준비된 다음 새 영역을 이어 붙입니다. 완료하거나 취소하면 원래 읽던 위치로 돌아옵니다. 최대 1,200만 픽셀 범위에서 확장합니다.

업데이트 화면의 현재 설치 버전과 다운로드할 버전은 구분됩니다. 5.7.0 DEBUG가 표시되면 이전 패키지 앱을 실행한 것입니다. 별도로 설치된 새 앱을 사용하세요.

## Omyaru 공통 책장

Android·Windows Omyaru와 공통 책장을 사용할 수 있습니다. **OAuth 프로젝트 통합이 먼저 필요합니다.** [이전 및 연결 안내](SHARED_BOOKSHELF_SETUP.md)를 따라 기존 자료를 내려받은 뒤 연결하세요. 책장 화면이 열려 있는 동안 15초마다 확인하며, 실제 계정 왕복 검증은 등록 변경 후 필요합니다.
