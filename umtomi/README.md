# Umtomi

Android reader and SwiftUI iOS reader. Existing platform architecture is retained.

- Android: `app/`, build with `gradlew.bat assembleDebug` (JDK 17+, Android SDK 35).
- iOS: `ios/`, generate the Xcode project using `project.yml`.
- Source and releases: https://github.com/omyeol/Umtomi
